Cloud sync

Keep one profile across devices

Field Kit is static, so automatic account sync needs a personal GitHub cloud slot. Paste a GitHub personal access token with Gists access, create a private Gist once, then save or load your planner profile from any device.

Recommended flow: create one private Gist here, note its ID, then use the same token and Gist ID on your other devices.
